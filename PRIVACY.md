# Privacy Policy

Last updated: July 14, 2026

YouTube Automatic Translation Language Auto-Setter does not collect, transmit, sell, or share personal information.

## Data stored

The extension stores one preference: the target subtitle language selected by the user. This preference is saved with Chrome's `storage.sync` API so it can follow the user between Chrome installations when browser sync is enabled.

## Website access

The extension runs only on YouTube pages. It reads and interacts with the visible YouTube player controls to select subtitle and auto-translation settings. It does not record browsing history, video history, searches, page content, or account information.

## Network communication

The extension does not operate an external server and does not send data to the developer or any third party. Chrome and YouTube may process data under their own privacy policies as part of their normal services.

## Analytics and advertising

The extension contains no analytics, advertising, tracking, or remote code.

## Changes

Material changes to this policy will be documented in this repository and reflected by the date above.

## Contact

Questions or privacy concerns can be submitted through the repository's GitHub Issues page.
